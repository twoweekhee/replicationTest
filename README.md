# DB Replication & Kafka Alert Service

### **⚙️ 프로젝트 개발 환경**

1. 통합개발환경(IDE) : InteliJ
2. JDK 버전 : JDK 17
3. 스프링 버전 : 5.2.7
4. 데이터 베이스 : Mysql, redis
5. 빌드 툴 : Gravy

### **⚒️ 프로젝트 기술 스택**

- 프론트엔드
    
    HTML, CSS, JS, React
    
- 백엔드
    
    Java, Spring Boot Framework, Kafka, SSE 
    
- 데이터베이스
    
    Mysql, redis, JPA
    

### **📜 구현 기능**

- Db replication
- Oauth2
- Oauth2 ; authorization, authentication
- jwt
- 대기열 구현 with 레디스
- 카프카 이용한 알림
